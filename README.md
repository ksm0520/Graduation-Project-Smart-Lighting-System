# 📣 Introduction

모바일 앱에서 조명 색상, 밝기, 전원, 자동화 루틴 등을 제어할 수 있는 스마트 조명 시스템입니다.

- **React Native 기반 모바일 앱**으로 조명을 제어
- **Raspberry Pi**를 활용한 IoT 하드웨어 제어
- **Express.js 서버**와 **PostgreSQL**을 통한 데이터 관리
- **자동화 루틴** 및 **알람 기능** 제공

<br>

# ✨ Features

- 🔆 **조명 제어**: 색상, 밝기, 전원 온/오프 제어
- ⏰ **자동화 루틴**: 시간대별 자동 조명 제어
- 🔔 **알람 기능**: 지정 시간에 조명 제어
- 📱 **실시간 동기화**: 서버와 실시간 상태 동기화
- 👤 **사용자별 설정**: 개인화된 조명 설정 저장
